# 031 Promos — página de links

Página estilo linktree da 031 Promos (canal do WhatsApp, Instagram e grupos Eletro, Fit, Tech e Achadinhos).

Feita com Vite + React + Tailwind. Para rodar localmente:

```bash
npm install
npm run dev
```

Publicação: Vercel (detecta Vite automaticamente; build `npm run build`, saída `dist`).
